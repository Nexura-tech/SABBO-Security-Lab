# SABBO Security Lab

A cybersecurity learning and portfolio platform focused on responsible security, practical learning, and open-source development.

## Overview

SABBO Security Lab is being developed as a public platform for showcasing cybersecurity projects, sharing learning resources, and documenting security concepts.

The initial version focuses on the portfolio and educational experience. Active security-testing features are not currently available.

## Goals

- Showcase open-source cybersecurity projects.
- Share cybersecurity learning resources.
- Build a clean, accessible, responsive dashboard.
- Encourage responsible and authorized security research.
- Develop future features with security and privacy in mind.

## Featured Projects

### Cyber Security Assessment Framework

A Python-based framework project for structured security assessment, developed with an emphasis on modular architecture, testing, and safe defaults.

### Cyber Nexus Security Toolkit

A Python security toolkit project intended to bring together useful security and system-analysis features.

Project links will be added after their repository URLs are verified.

## Technology Stack

- React
- TypeScript
- Vite
- CSS

## Development Status

**Status:** Early development

The current focus is the frontend dashboard, project portfolio, and learning-resource sections. Backend services and active security-testing functionality are future work and will require appropriate security controls.

## Responsible Use

This project supports ethical learning and authorized security work. Any future testing features must include appropriate scope restrictions and safeguards. Only test systems you own or have explicit permission to assess.

## Local Development

### Requirements

- Node.js compatible with the installed Vite version
- npm

### Setup

```bash
git clone <YOUR_REPOSITORY_URL>
cd SABBO-Security-Lab
npm install
npm run dev
```

Open the local URL printed by Vite.

### Verification

```bash
npm run build
npm run lint
```
